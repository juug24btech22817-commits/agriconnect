# AgriConnect 🌾

Empowering the agricultural ecosystem through technology, transparency, and direct trade.

## 🚀 Overview
AgriConnect is a comprehensive platform designed to bridge the gap between farmers and consumers. By eliminating intermediaries, we ensure better profit margins for farmers and fresher produce for consumers.

## ✨ Key Features
- **Live Weather Tracker**: Real-time updates and smart agri-advisories based on local conditions.
- **Direct Marketplace**: Seamless trade between farmers and buyers.
- **Success Stories**: Real-world impact stories from our community.
- **Market Price Dashboard**: Transparent, real-time pricing for 50+ crops.

## 🛠️ Tech Stack
- **Frontend**: React, Framer Motion, Tailwind CSS, Lucide Icons.
- **State Management**: React Context API.
- **Animations**: Framer Motion for premium UI/UX.
